## 🧭 About me

- 📊 **Applied statistics** — my thesis research is in spatial statistics and text corpora, and most of my repos answer one question: *what can official data tell us?*
- 🌏 **Indonesian public data nerd** — BMKG earthquakes, BPS regional statistics, DJPK village-fund data, the Satu Data catalog. If the government publishes it, I want to visualize it.
- 🏆 **Kaggle competitor** — NFL Big Data Bowl 2027 (sports kinematics) and Name That LLM (fingerprinting 18 frontier models).
- 🛠 **I ship dashboards, not just notebooks** — Streamlit apps and Next.js frontends, all open source.
- 🎯 **Goal:** make official statistics approachable, interactive, and fun.
