## Hi, I'm Zhabyan 👋

Statistics & Data Science student at **Universitas Negeri Semarang**. I build things that turn official numbers into
something you can actually click: BMKG earthquake feeds, BPS regional statistics, DJPK budget data, the Satu Data catalog.
Every project below is open source and either live, or one command away from being live.

|  |  |
|:--|:--|
| 🔭 **Building** | Open-data dashboards for Indonesia — Next.js 15 + Streamlit, all deployable on a student budget |
| 🏆 **Competing** | Kaggle — *NFL Big Data Bowl 2027* (sports tracking kinematics) and *Name That LLM* (fingerprinting 18 frontier models) |
| 📚 **Studying** | Spatial statistics, forensic data analysis, text mining, statistical computing |
| 🎯 **Mission** | Make official statistics approachable, interactive, and honestly interpreted |
